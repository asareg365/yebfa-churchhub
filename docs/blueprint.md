# **App Name**: Yebfa ChurchHub

## Core Features:

- Multi-tenant Church Portal: A sophisticated glassmorphic dashboard providing complete data isolation for multiple religious organizations using a multi-tenant SaaS architecture.
- Secure Tenant Isolation: Enterprise-grade data scoping using tenantId and custom Firebase security rules to ensure zero data leaks between different churches.
- AI Pastoral Insight Tool: An AI-powered tool that uses reasoning to analyze attendance trends and financial data to suggest personalized outreach strategies for congregation growth.
- Automated Birthday SMS System: A background engine utilizing Hubtel and Africa’s Talking SMS integrations for personalized, church-branded birthday greetings.
- QR Attendance System: Real-time check-in system where members use generated QR codes for instant service and department attendance logging.
- Financial Ledger & Reporting: Comprehensive tracking for tithes, offerings, and expenses with automated PDF receipt generation and visualization charts.
- Dynamic Permissions Engine: A sophisticated role-based access control system allowing church admins to toggle specific menu items and action permissions per user.

## Style Guidelines:

- Primary Color: Electric Amethyst (#9F7AEA) for a spiritual, high-energy, and modern aesthetic.
- Background: Deep Cosmic Void (#030712) with a subtle mesh gradient overlay for an ultra-premium dark mode look.
- Accent Color: Radiant Neo-Mint (#10B981) for positive financial indicators and successful status badges.
- Headlines use 'Syncopate' for a futuristic, expansive feel; body text uses 'Plus Jakarta Sans' for ultra-crisp readability.
- Minimalist duotone icons with a subtle outer-glow effect in Electric Amethyst to enhance the glassmorphic depth.
- Floating sidebar navigation with high-density backdrop blur (40px) and micro-shadows to separate UI layers.
- Liquid-smooth spring transitions and parallax card effects that react to mouse hover for a tactile, amazing user experience.
